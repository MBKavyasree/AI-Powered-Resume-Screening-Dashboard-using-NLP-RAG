# 🤖AI-Powered-Resume-Screening-Dashboard-using-NLP-RAG
AI-Powered Resume Screening Dashboard uses NLP and RAG to match job descriptions with resumes. Sentence-BERT embeddings and FAISS enable semantic search, while a HuggingFace FLAN-T5 model generates explanations for candidate-job fit. An interactive Gradio dashboard displays results for faster and smarter recruitment.

# 🚀 Features

Semantic matching of resumes and job descriptions

Sentence-BERT embedding model

FAISS vector database for similarity search

RAG-based AI explanation generation

Interactive Gradio dashboard

Runs fully on Google Colab

# 🧠 Tech Stack

Python

Sentence-Transformers (Sentence-BERT)

FAISS

HuggingFace Transformers (FLAN-T5)

Gradio

Google Colab
